## 🎯 Проект (задание)

**GeoPoint Analyzer** — веб-сервис анализа территории по координатам: показывает **жилые дома по этажности** и **супермаркеты** в заданном радиусе. Данные — OpenStreetMap через Overpass API (бесплатно, без ключей).

Архитектура (3 модуля):
- `overpass_client.py` — «курьер»: запросы к Overpass API (зеркала, ретраи, User-Agent)
- `analyzer.py` — «сортировщик»: классификация зданий по этажности, супермаркеты с расстояниями, текстовый отчёт
- `app.py` — «витрина»: интерфейс Gradio + сервер FastAPI (включая эндпоинт `/set_point` для выбора точки кликом по карте)

Ключевые возможности:
- Ввод координат вручную или **выбор точки кликом на карте**
- Текстовый отчёт: дома 1-3 / 4-9 / 10+ этажей / неизвестно
- **Карта с подсветкой зданий** цветом по этажности + легенда
- Супермаркеты с адресами и расстояниями (формула Хаверсинус)
- Надёжность: 4 зеркала Overpass, ретраи с уважением к `Retry-After`, объединённый запрос

## 🔌 Context7 MCP — обязательно

Context7 даёт свежую документацию библиотек и защищает от ошибок из-за устаревших методов (знания модели могут быть устаревшими).

**Первый запуск:**
1. Проверь: вызови tool `resolve-library-id` с параметром `gradio`
2. Если нет — установи:
   a. Проверь `npx`: `npx --version`
   b. Если Node.js нет — поставь сам в зависимости от ОС:
      - Windows: `winget install OpenJS.NodeJS.LTS`
      - macOS: `brew install node`
      - Linux (Debian/Ubuntu): `sudo apt install nodejs npm`
   c. Зарегистрируй MCP-сервер в настройках IDE на уровне **USER**:
      ```json
      { "mcpServers": { "context7": { "command": "npx", "args": ["-y", "@upstash/context7-mcp"] } } }
      ```
   d. Запасной вариант (если локальный не работает):
      ```json
      { "mcpServers": { "context7": { "type": "http", "url": "https://mcp.context7.com/mcp" } } }
      ```
3. Результат подключения — в `progress.md`, грабли — в `LESSONS.md`

**Использование:** всегда перед написанием кода с любой библиотекой (`resolve-library-id` → `query-docs`). Базовый синтаксис Python — не нужно.

**Если Context7 недоступен** — всё равно выполняй задачу. Состояния «не работаю» не существует.

## 🧪 Запуск, остановка и проверка сервиса

**Запуск** одной командой:
```bash
source venv/bin/activate && python app.py
```
Внутри `app.py` используется `uvicorn.run(app)` — так работают и интерфейс Gradio, и FastAPI-эндпоинты (`/set_point`). Открыть в браузере: **http://127.0.0.1:7860**

**Остановка/перезапуск — ТОЛЬКО по PID, никогда по имени процесса:**
```bash
lsof -ti :7860 -sTCP:LISTEN | xargs kill
```
⚠️ Почему: `pkill -f "python app.py"` **не находит** процесс (в командной строке он выглядит как `Python app.py` — заглавная P от Homebrew; pkill чувствителен к регистру). Старый сервер переживает перезапуск, порт занят, новый процесс умирает — и пользователь видит старый код. Это уже случалось.

**Проверка, что всё работает:**
- `curl http://127.0.0.1:7860/` → `200 OK`
- `curl -X POST http://127.0.0.1:7860/set_point -H "Content-Type: application/json" -d '{"lat": 54.99, "lon": 82.99}'` → `{"ok":true}`
- Сквозной тест в браузере (Playwright): клик по карте → «Взять точку с карты» → «Анализировать» → отчёт и полигоны зданий на карте
- Логи ошибок пишутся в `logs/`, а не только в консоль

## 🔒 Безопасность

- `.env` обязательно в `.gitignore`, никогда не коммитится
- `.env.example` — шаблон без реальных секретов, можно коммитить
- **Никогда** не логировать: API-ключи, содержимое `.env`, личные данные пользователей
- Валидация входных данных **до** запроса: широта -90..90, долгота -180..180, радиус 50..5000 м
- CORS открыт (`allow_origins=["*"]`) — осознанно: карта живёт в iframe, и браузер считает её запросы «чужими». Для локального сервиса это безопасно; для публичного — ограничить
- В коде и логах не должно быть секретов и ключей
