# 🗺️ GeoPoint Analyzer

Веб-сервис для анализа территории по координатам: **жилые дома по этажности** и **супермаркеты** в заданном радиусе.

Точку можно задать координатами вручную или **выбрать кликом на карте**. Каждый дом на карте подсвечен контуром своего цвета — по количеству этажей.

Данные — **OpenStreetMap** через **Overpass API**: бесплатно, без ключей и регистрации.

> Цель проекта: обучение сотрудников быстрому способу проверки гипотез с использованием стека AI.

---

## ✨ Возможности

- 📊 **Анализ жилой застройки**: дома распределяются по группам — 1–3 этажа, 4–9 этажей, 10+ этажей, этажность неизвестна
- 🛒 **Поиск супермаркетов**: названия, адреса и расстояния от точки (формула Хаверсинус)
- 🗺️ **Выбор точки кликом на карте**: координаты подставляются в поля автоматически
- 🏘️ **Подсветка зданий на карте**: полигоны зданий цветом по этажности + легенда
- 🔁 **Надёжность**: 4 зеркала Overpass API, ретраи с уважением к `Retry-After`, переключение при перегрузке
- 🛡️ **Защита от ошибок**: валидация входных данных, понятные сообщения вместо traceback

### Цвета зданий на карте

| Цвет | Категория |
|------|-----------|
| 🟩 зелёный | 1–3 этажа (малоэтажка) |
| 🟨 жёлтый | 4–9 этажей (среднеэтажка) |
| 🟥 красный | 10+ этажей (высотки) |
| ⬜ серый | этажность неизвестна |

## 🚀 Быстрый старт

```bash
# 1. Создайте виртуальное окружение и установите зависимости
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 2. Запустите сервер
python app.py
```

Или через скрипт (он сам остановит старый сервер, если тот работает):

```bash

./start.sh stop     # остановить
```

Откройте в браузере: **http://127.0.0.1:7860**

## 📋 Как пользоваться

### Способ 1 — координаты вручную

1. Введите **широту** (от -90 до 90, например `54.640406`) и **долготу** (от -180 до 180, например `83.303459`)
2. Укажите **радиус поиска** — от 50 м (двор) до 5 000 м (район), по умолчанию 1 000 м
3. Нажмите **«Анализировать»**

### Способ 2 — выбор точки на карте 🗺️

1. Прокрутите страницу до карты **«Или выберите точку на карте»**
2. **Кликните** по нужному месту — появится маркер
3. Нажмите **«Взять точку с карты»** — координаты подставятся в поля сами
4. Нажмите **«Анализировать»**

### Результаты

- 📊 **Текстовый отчёт**: количество жилых зданий по этажности
- 🛒 **Список супермаркетов**: названия, адреса, расстояния от точки
- 🗺️ **Интерактивная карта**: дома подсвечены контурами по этажности, легенда в левом нижнем углу

## 🔌 API

Сервер поднимает и FastAPI-эндпоинты. Пример — установка точки кликом по карте:

```bash
curl -X POST http://127.0.0.1:7860/set_point \
  -H "Content-Type: application/json" \
  -d '{"lat": 54.99, "lon": 82.99}'
# → {"ok":true}
```

## 🛠 Технологии

- **Backend**: Python 3.11, FastAPI, uvicorn
- **Frontend**: Gradio 6.23
- **Данные**: Overpass API (OpenStreetMap), запрос `out geom` для контуров зданий
- **Визуализация**: Folium (полигоны, маркеры, легенда)
- **Математика**: формула Хаверсинус для расстояний
