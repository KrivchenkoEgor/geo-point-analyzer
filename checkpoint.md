# Checkpoint — GeoPoint Analyzer

## Дата: 2026-08-13

## Что сделано
- Исследовано окружение: macOS ARM, Python 3.11 (Homebrew), Node.js 26
- Создана структура проекта с папками: uploads/, logs/, reports/
- Реализованы все модули:
  - `overpass_client.py` — запросы к OpenStreetMap с User-Agent, зеркалами и retry-логикой
  - `analyzer.py` — парсинг, группировка по этажам, извлечение супермаркетов, форматирование с расстояниями
  - `app.py` — FastAPI + Gradio UI с валидацией, картой и текстовым отчётом
- Проведен сквозной тест: реальный запрос к Overpass API, получение данных, отображение в UI
- Записаны уроки в `LESSONS.md`: 3 грабли Overpass, миграция Gradio 6.0, выбор Python версии
- Рассчитаны расстояния от точки до каждого супермаркета по формуле Хаверсинус
- Убраны чёрные полосы (символы █) из текстового отчёта
- **Добавлен выбор точки на карте**: folium-карта с кликом → POST /set_point → кнопка «Взять точку с карты» подставляет координаты в поля
- Запуск переведён на `uvicorn.run(app)` — FastAPI-эндпоинты (/set_point) работают вместе с Gradio
- Сквозной тест новой функции пройден в браузере (Playwright): клик → точка в полях → анализ от новой точки (125 зданий, 6 супермаркетов)
- **Подсветка зданий на карте**: запрос переведён на `out geom`, каждое здание рисуется контуром цвета по этажности (зелёный/жёлтый/красный/серый) + легенда. Проверено в браузере: 116 контуров на карте
- **AGENTS.md актуализирован полностью** (2026-08-13): убраны устаревшие секции (report-service, agents_config, LLM/DeepSeek), актуализированы стек, структура, команды запуска/остановки, /set_point, чек-лист
- **Скрипт `start.sh`**: запуск/остановка одной командой, сам убивает старый сервер по PID. Проверен: HTTP 200, /set_point {"ok":true}, stop работает. README обновлён
